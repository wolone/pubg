# PUBG 回放地图资源

这些低分辨率地图底图来自固定版本的 [`trevoedwards/pubg-api-assets`](https://github.com/trevoedwards/pubg-api-assets) 仓库（commit `dfd03751909faf19716d5cd2395cbbe26f098a77`），用于在比赛回放中为航线、目标玩家轨迹和圈层提供稳定的本地地图参照。

文件名按 PUBG Telemetry 的地图 ID 保存。`Baltic_Main`、`Desert_Main` 等历史 Telemetry ID 分别对应 Erangel、Miramar 等地图资源。资源使用须遵守 [PUBG Terms of Use](https://developer.pubg.com/tos) 与 [Player-created Content 政策](https://www.pubg.com/player-created-content/)。
