# PUBG 回放地图资源

这些 4096×4096 地图底图与 [`pubgsh/client`](https://github.com/pubgsh/client) 的回放地图资源保持一致，用于在比赛回放中为航线、目标玩家轨迹和圈层提供清晰、稳定的本地地图参照。资源按 JPEG 格式存储，避免高倍缩放时使用 819×819 缩略图造成明显模糊。

文件名按 PUBG Telemetry 的地图 ID 保存。`Baltic_Main`、`Desert_Main` 等历史 Telemetry ID 分别对应 Erangel、Miramar 等地图资源；补给箱图标位于 `public/assets/`，与回放事件图层配套使用。资源使用须遵守 [PUBG Terms of Use](https://developer.pubg.com/tos) 与 [Player-created Content 政策](https://www.pubg.com/player-created-content/)。
